# قائمة التجربة اليدوية (على الهاتف)

قبل البدء: **صدّر نسخة احتياطية** من الإعدادات إن كان على الهاتف نسخة قديمة. علّم ✅ أو ❌ وأرسل لي ما فشل.

## 1) أول تشغيل
- [ ] يفتح التطبيق دون تعطل، وتظهر مجرة «ملاحظاتي».
- [ ] الواجهة عربية من اليمين لليسار والمظهر داكن.

## 2) المجرات والكواكب
- [ ] إنشاء مجرتين باسمين مختلفين وكوكبين مختلفين (مثل زحل والمشتري).
- [ ] خريطة المجرات تعرض كل مجرة بشكل كوكبها وألوانه الحقيقية (حلقات زحل ظاهرة).
- [ ] اللمس على كوكب مجرة يفتحها؛ السحب والتكبير يعملان.
- [ ] إعادة تسمية مجرة وتغيير كوكبها تُحدّثان البطاقة والخريطة.

## 3) الملاحظات والمحرر
- [ ] «ملاحظة جديدة»: اكتب نصًا بلا عنوان؛ بعد ثانية تظهر «تم الحفظ» والعنوان أول سطر.
- [ ] اكتب بسرعة ثم ارجع: تظهر الملاحظة **مرة واحدة** في القائمة (لا نسخة مكررة).
- [ ] أغلق التطبيق من التطبيقات الأخيرة وأعد فتحه: الملاحظة باقية بنصها.
- [ ] «قائمة مهام» ثم Enter ينشئ بندًا جديدًا؛ «إنجاز» يبدّل ☐ و☑؛ Enter على بند فارغ يُنهي القائمة.
- [ ] النجمة تثبّت الملاحظة فتصير أولى في القوائم، والتثبيت يبقى بعد إعادة التشغيل.
- [ ] زر المشاركة يفتح قائمة التطبيقات بنص الملاحظة (العنوان ثم النص).

## 4) البحث
- [ ] ابحث بكلمة «الطبخ» عن ملاحظة فيها «طبخ»؛ وبـ«ادارة» عن «إدارة»؛ وبـ«مدرسه» عن «مدرسة».
- [ ] البحث باسم مجرة يعرض المجرة وكل ملاحظاتها.

## 5) الروابط والاقتراحات
- [ ] من أسفل المحرر: ربط ملاحظتين بنوع؛ يظهر الرابط خطًا ثابتًا في المجرة وفي تبويب «الروابط».
- [ ] رابط مكرر يُرفض برسالة؛ ربط الملاحظة بنفسها يُرفض.
- [ ] ملاحظتان بكلمة مشتركة تُنتجان اقتراحًا (خط متقطع)؛ «قبول» يجعله ثابتًا، «رفض» يخفيه ويبقى مخفيًا بعد إعادة التشغيل.
- [ ] «دمج» يعرض اقتراحًا بقالب؛ «حفظ كملاحظة جديدة» ينشئ ملاحظة داخل المجرة.
- [ ] ملاحظة تحوي اسم مجرة أخرى تُظهر لافتة «نقلها إلى …»، والنقل يحفظ نصها وروابطها.

## 6) الحذف والتراجع والسلة
- [ ] حذف ملاحظة يعرض «تراجع»؛ الضغط عليه يعيدها بروابطها.
- [ ] حذف مجرة فيها ملاحظات وروابط ثم «تراجع» يعيد كل شيء.
- [ ] بعد اختفاء الشريط: «الإعدادات» ← «فتح السلة» تعرض المحذوف، و«استعادة» تعيده، و«حذف نهائي» يحذفه بتأكيد.
- [ ] المحذوف لا يظهر في القوائم ولا البحث ولا الخريطة.

## 7) النسخة الاحتياطية
- [ ] «تصدير» يحفظ ملف JSON تختار مكانه.
- [ ] «استيراد» للملف نفسه لا يكرر شيئًا ويعرض عدد المتخطى.
- [ ] ملف غير صالح يعرض رسالة ولا يغيّر شيئًا.

## 8) التحديث فوق نسخة قديمة (الترحيل)
- [ ] تثبيت هذه النسخة فوق نسخة سابقة موقّعة بالمفتاح نفسه يفتح دون تعطل وببيانات كاملة. (إن ظهر تعطل: أرسل لي رسالة الخطأ.)
