# جسر الأفكار (IdeaBridge)

تطبيق ملاحظات عربي (RTL) لمستخدم واحد، يعرض ملاحظاتك كواكب في مجرات. كل البيانات على جهازك، بلا حسابات ولا إنترنت ولا إعلانات.

- الحزمة: `com.ideabridge.app` — Kotlin + Jetpack Compose + Material 3 + Room.
- التصنيف = **المجرة**: اسمها تصنيفها ولها كوكبها (الأرض، المريخ، المشتري، زحل، الزهرة، نبتون، أورانوس، عطارد).

## الميزات
- **الملاحظات:** محرر بحفظ تلقائي، قوائم مهام (☐/☑) ونقاط، تثبيت، مشاركة خارج التطبيق.
- **المجرات:** إنشاء وتعديل وحذف، خريطة المجرات (روابط نصية بينها) أو قائمة، واقتراح نقل ملاحظة إلى المجرة الأنسب.
- **كواكب الملاحظات:** عرض بالسحب والتكبير، روابط محفوظة (خطوط ثابتة) واقتراحات (خطوط متقطعة) بنوع مقترح (تشابه، مشكلة وحل، سبب ونتيجة) ودمج ملاحظتين.
- **البحث:** يتسامح مع التشكيل والتطويل وأشكال الألف والياء والتاء المربوطة و«ال».
- **الاستقبال:** مشاركة نص من أي تطبيق إلى «جسر الأفكار» تُنشئ ملاحظة، واختصار «ملاحظة جديدة» عند الضغط المطوّل على الأيقونة.
- **قفل التطبيق (اختياري):** يستعمل قفل الجهاز عبر نافذة النظام الرسمية، ويعيد القفل بعد 30 ثانية في الخلفية.
- **الأمان:** تراجع فوري عن الحذف، وسلة محذوفات 30 يومًا، ونسخة احتياطية JSON (تصدير واستيراد إضافي لا يحذف شيئًا).

## البنية
| المسار | المحتوى |
|---|---|
| `app/.../data` | Room: الكيانات، DAO، المستودع، الترحيلات (الإصدار 5) |
| `app/.../engine` | منطق بحت قابل للاختبار على JVM: معالجة العربية، TF-IDF، اقتراح الروابط والمجرات، الدمج، التخطيط، النسخ الاحتياطي، البحث |
| `app/.../ui` | شاشات Compose |
| `app/src/test` | اختبارات JVM |
| `app/src/androidTest` | اختبارات المحاكي (Room والترحيل والسلة والاستيراد...) |
| `.github/workflows` | `android-build.yml` (اختبارات + APK تجريبي)، `release.yml` (APK موقّع، يدوي) |
| `docs/RELEASE.md` | إنشاء مفتاح التوقيع وبناء الإصدار |
| `docs/QA.md` | قائمة تجربة يدوية على الهاتف |

## البناء
`gradle` يُثبَّت تلقائيًا في GitHub Actions (الإصدار 8.9، JDK 17). لإنشاء `gradlew` محليًا: `gradle wrapper`.

## الخصوصية والأذونات
لا أذونات في الـ Manifest. لا اتصال بالشبكة. التصدير والاستيراد يستعملان منتقي ملفات النظام.

## حدود معروفة
- اقتراح الأنواع قائم على قوائم كلمات صريحة قصيرة (`engine/Lexicon.kt`) ولا يفهم المعنى.
- الكلمة التي تتكرر في أكثر من 60% من ملاحظات مجرة (5 ملاحظات فأكثر) تُهمل في الاقتراحات.
- الرابط بين ملاحظتين من مجرتين مختلفتين يظهر في تبويب «الروابط» فقط.
